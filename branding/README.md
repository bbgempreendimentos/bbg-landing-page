# Kit de marca — BBG Empreendimentos

Peças prontas para Instagram, WhatsApp, Meta Business (BM), Facebook e LinkedIn, seguindo a mesma identidade do site.

## Identidade

| Elemento        | Valor                                   |
| --------------- | --------------------------------------- |
| Azul-marinho    | `#0A1628` (fundo principal)             |
| Marinho claro   | `#12233B` / `#192E49` (cartões)         |
| Verde-esmeralda | `#22C58B` (destaque, ações)             |
| Verde claro     | `#71E6B6` (brilhos, detalhes)           |
| Papel           | `#EAF0F7` (texto sobre fundo escuro)    |
| Cinza-azulado   | `#9FB0C6` (texto secundário)            |
| Títulos         | Space Grotesk (600)                     |
| Textos          | Inter (400–700)                         |

Regras rápidas:

- O fundo é sempre o azul-marinho; o verde aparece em **uma** parte do título, nunca no texto todo.
- Rótulos em caixa alta e espaçados (`O QUE FAZEMOS`, `01 / SISTEMAS`) abrem cada peça.
- O símbolo do cubo não deve ser redesenhado, esticado nem recolorido fora das versões em `logo/`.

## Editar ou gerar novas peças

Todas as peças são geradas a partir de `_fonte/kit.template.html` (HTML + CSS com as cores e fontes do site):

```bash
python3 branding/_fonte/gerar.py                    # gera tudo
python3 branding/_fonte/gerar.py post-01-apresentacao   # gera só uma peça
```

Requer o Google Chrome instalado. Para criar uma peça nova, copie um bloco `A['post-…']` no template, mude o nome e o conteúdo e rode o script. O desenho do símbolo vem de `_fonte/logo-path.txt`, que foi vetorizado a partir de `public/bbg-logo.webp` com `_fonte/vetorizar-logo.py`.

## Pendente

- **Canais de contato:** quando o WhatsApp/e-mail oficial estiver definido, ele pode entrar no post 10, no story 03 e na capa do Facebook.
- **Prévia do link do site:** para usar `meta-bm/og-compartilhamento.png` como prévia no WhatsApp, copie o arquivo para `public/` e adicione a meta tag `og:image` no `index.html`.
